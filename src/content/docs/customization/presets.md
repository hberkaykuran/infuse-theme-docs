# Styles: Infuse and Utility

Infuse ships with two styles. They share the same sections, blocks, and layout tools. What changes is the personality: fonts, corner radius, density, and motion. Switch between them in *Theme settings → Design preset*.

## Side by side

|              | Infuse                                             | Utility                                             |
| ------------ | --------------------------------------------------- | ---------------------------------------------------- |
| Feel         | Rounded and expressive                               | Engineered and dense                                  |
| Display font | A soft self-hosted serif that loads with the theme   | Your system's monospace font, so nothing downloads    |
| Corners      | Generously rounded                                   | Square, no radius at all                               |
| Accent       | Warm coral                                           | Rust red                                               |
| Motion       | Springy                                              | Instant, no transitions                                |
| Best for     | Playful, modern brands                               | Technical, spec-driven, or minimal brands              |

## How to switch

1. Open the theme editor and go to *Theme settings → Design preset*.
2. Choose **Infuse** or **Utility**.
3. Review your pages, since the change affects fonts and spacing across the theme.
4. Adjust your colour schemes if you want the accent to match the new style.

The preset and your colour schemes are independent. You can run the Infuse style with your own colours, or the Utility style with a different accent. Set colours under [Theme settings → Colors](/docs/customization/theme-settings).
