# Styles: Infuse and Heirloom

Infuse ships with two styles. They share the same sections, blocks, and layout tools. What changes is the personality: fonts, corner radius, and motion. Switch between them in *Theme settings → Design preset*.

## Side by side

|              | Infuse                                            | Heirloom                                          |
| ------------ | ------------------------------------------------- | ------------------------------------------------- |
| Feel         | Rounded and expressive                            | Classic and refined                               |
| Display font | A soft self-hosted serif that loads with the theme | A traditional serif you pick from Shopify's font list |
| Corners      | Generously rounded                                | Square, restrained                                |
| Accent       | Warm coral                                        | Amber                                             |
| Motion       | Springy                                           | Understated                                       |
| Best for     | Playful, modern brands                            | Heritage and premium brands                       |

## How to switch

1. Open the theme editor and go to *Theme settings → Design preset*.
2. Choose **Infuse** or **Heirloom**.
3. Review your pages, since the change affects fonts and spacing across the theme.
4. Adjust your colour schemes if you want the accent to match the new style.

The preset and your colour schemes are independent. You can run the Infuse style with your own colours, or the Heirloom style with a coral accent. Set colours under [Theme settings → Colors](/docs/customization/theme-settings).
