Quick start

From a fresh install to a finished home page. Every step happens in the Shopify editor, and none of them need code.

1

Add the theme

Install Infuse from the Theme Store, then open it in the editor from Online Store → Themes. Keep it unpublished while you set things up; the preview link works either way.

2

Pick a preset

Under Theme settings → Design, choose Infuse or Utility. Fonts, corners, colors and motion all switch together, so try both before you commit.

Tip

Both presets share the same sections and settings. Nothing you build is lost when you switch, so experiment freely.

3

Logo and menus

Upload your logo in the header section, then point the header and footer at your menus under Navigation. A text wordmark is used until a logo is set.

4

Build the home page

Start from the default layout: hero, featured collection, story, testimonials. Add, remove and reorder sections freely; each one keeps its own settings.

The sections reference lists everything you can add, with a picture of each.
